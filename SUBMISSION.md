## Quick start (no credentials needed)

```bash
git clone https://github.com/thiru-o-o/lila-games-designer-god-s-eye
cd lila-games-designer-god-s-eye/gods-eye
npm install
npm run dev        # → http://localhost:5173
```

The app ships with pre-built Parquet files — no Supabase account or backend required.
